# Sewing Workshop Management System

A full-stack management system for sewing workshops, built with **Angular, TypeScript, Node.js, Express, and SQLite**.

The system helps manage **customers, workers, orders, production, payments, products, financial transactions, and account cycles** through a dynamic and user-friendly admin dashboard.

### Technologies

* Angular
* TypeScript
* Node.js
* Express.js
* SQLite
* Angular Signals
* REST API

### Main Features

* Customer management
* Worker management
* Production tracking
* Orders management
* Payments and financial transactions
* Account cycle management
* Product management
* Dynamic dashboards and statistics
* Different workflows for different worker types
